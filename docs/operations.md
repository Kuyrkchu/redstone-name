# Эксплуатационные заметки

Состояние ниже отражает диагностику VPS на 2026-11-20; перепроверьте его перед развёртыванием, так как сервер мог измениться.

## WireGuard

- На сервере запущен обычный интерфейс `wg0`; `wg-quick@wg0` active, UDP-порт `51820` слушается.
- Forwarding IPv4/IPv6 включён; правила NAT для VPN-подсети присутствуют.
- Peer клиента с адресом `10.66.66.4/32` есть в `wg0`, его адрес назначения IPv6 — `fd42:66:66::4/128`.
- Проверенная локальная клиентская конфигурация направляет IPv4 и IPv6 через туннель; публичный ключ, полученный из её приватного ключа, совпал с peer `.4` на сервере. Сами конфиг и ключи в репозитории намеренно отсутствуют.
- На момент проверки у peer `.4` не было handshake или трафика. Это означает, что сервер не зафиксировал установление сессии; само по себе не указывает, блокирует ли клиентское устройство отправку, мобильная сеть или внешний firewall провайдера.
- Локальная политика INPUT была ACCEPT, `ufw` не установлен. Это не подтверждает состояние внешних security groups у хостера.

Для безопасной диагностики на VPS используйте отдельные read-only запросы:

```sh
wg show wg0 latest-handshakes
wg show wg0 transfer
wg show wg0 allowed-ips
ss -lunp | grep ':51820'
```

Не публикуйте `wg show ... dump`, содержимое `/etc/wireguard/wg0.conf`, клиентские `.conf`, QR или sing-box JSON: они могут раскрыть приватные ключи. Для реальной проверки handshake клиентский профиль должен быть включён на телефоне.

WireGuard не сообщает достоверный непрерывный статус «подключён прямо сейчас». Админка может показывать последнюю временную отметку handshake и счётчики RX/TX, а также системную загрузку сервера; эти показатели не равнозначны точному live-статусу каждого устройства.

## Приложения

Текущий сервер выдаёт стандартный WireGuard-профиль. Официальное приложение WireGuard — прямой вариант для `.conf`/QR; в AmneziaVPN следует пробовать импорт `.conf`. Опубликованный список форматов HAPP не содержит WireGuard. Прямой импорт стандартного `.conf` в v2RayTun не подтверждён для каждой версии. Визуальные карточки и ссылки на первоисточники лежат в `docs/`.

## Что не развёрнуто

Staging-код Telegram-бота в репозитории — не подтверждение боевого развёртывания. Peer provisioning для множества пользователей/устройств, отзыв каждого доступа через бот, промокоды и системная статистика пока не реализованы в этом исходнике. Перед любым запуском проверьте пути к файлам, systemd unit, владельца/права на секреты и актуальный Telegram token на сервере.
